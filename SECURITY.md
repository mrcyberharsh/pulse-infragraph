# Security Policy# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Do not report vulnerabilities through public GitHub issues.**

Report privately:

- **Maintainer / Developer:** Harsh Saini — cyber.h4rsh@zohomail.in
- **Manager:** Prachi Sharma — manager.prachi@zohomail.in
- **Organization:** MR Cyber Pulse

Include: issue type, source file paths, reproduction steps, impact, suggested fix.

Acknowledgement within **7 days**. Coordinated disclosure.

## Out of Scope

- Findings about third-party domains from authorized scans
- Inaccurate fingerprints or heuristic risk scores (documented limitations)
- Missing optional dependencies (Neo4j, ReportLab)

## Safe Harbor

Supported for researchers who make good-faith efforts to avoid privacy violations, data destruction, and service interruption; only interact with assets they own or are permitted to assess; report privately with reasonable fix time.
